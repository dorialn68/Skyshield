# Lighting environments

The three 1K HDR environments in this directory are sourced from Poly Haven
and released under the Creative Commons Zero (CC0) license.

- `apron-cloudy-1k.hdr` — [Hanger Exterior Cloudy](https://polyhaven.com/a/hanger_exterior_cloudy)
- `hangar-interior-1k.hdr` — [Hangar Interior](https://polyhaven.com/a/hangar_interior)
- `inspection-workshop-1k.hdr` — [Aerodynamics Workshop](https://polyhaven.com/a/aerodynamics_workshop)

Source files were downloaded from Poly Haven's official 1K HDR endpoints and
verified against the MD5 checksums published by the Poly Haven API.
