# Lighting environments

The five presentation-safe 1K HDR environments in this directory are sourced from Poly Haven
and released under the Creative Commons Zero (CC0) license.

- `studio-softbox-1k.hdr` — [Studio Small 08](https://polyhaven.com/a/studio_small_08)
- `daylight-noon-1k.hdr` — [Qwantani Noon (Pure Sky)](https://polyhaven.com/a/qwantani_noon_puresky)
- `sky-partly-cloudy-1k.hdr` — [Kloppenheim 03 (Pure Sky)](https://polyhaven.com/a/kloppenheim_03_puresky)
- `golden-sunset-1k.hdr` — [Belfast Sunset (Pure Sky)](https://polyhaven.com/a/belfast_sunset_puresky)
- `night-moonrise-1k.hdr` — [Qwantani Moonrise (Pure Sky)](https://polyhaven.com/a/qwantani_moonrise_puresky)

Source files were downloaded from Poly Haven's official 1K HDR endpoints and
verified against the MD5 checksums published by the Poly Haven API.
